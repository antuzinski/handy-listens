# Словарь Handy Listens: как писать ← как слышит распознавание.
# Строки, начинающиеся с #, не используются. Изменения работают со следующей диктовки,
# перезапуск не нужен.
#
# Формат строк:
#   ИИшный ← иишный                 замена целого слова; заглавная буква в начале сохраняется
#   бэклог* ← беклог*, бек лог*     * — любое окончание: «в беклоге» → «в бэклоге»
#   Cursor ← курсор (only when it is about the code editor, not the mouse pointer)
#                                   скобки со словом only или только — условие. Такую замену
#                                   делает только LLM-чистка, правило её не трогает. Если в
#                                   условии есть «слова» в ёлочках, условие касается только их.
#   Figma                           строка без ← — термин, который подсказывается Whisper
#   > Связная фраза.                строка с > — фраза-подсказка для Whisper

> На созвоне обсуждаем роадмап и бэклог: A/B-тест онбординга, MVP чат-бота, ретеншн и NPS. Задачи в джире, документы в Confluence, макеты в Figma, заметки в Notion. Вайб-кодинг в Cursor с Claude Code и Codex, пул-реквест на GitHub и деплой. ИИшные фичи на LLM и ИИ-агентах.

# Продукт
A/B-тест* ← абтест*, аб-тест*, аб тест*, эйби тест*, эй би тест*
бэклог* ← беклог*, бек лог*
роадмап* ← роудмап*, роуд мап*, роад мап*
запитчить ← за питчить, запичить
MVP ← эмвипи, эм ви пи, мвп
CJM ← сиджейэм, си джей эм
PRD ← пиардэ, пи ар ди
NPS ← энпиэс, эн пи эс
ретеншн ← ретеншен, ритеншн
стейкхолдер* ← стэйкхолдер*, стейк холдер*
юнит-экономик* ← юнит экономик*
фидбек* ← фидбэк*, фид бек*
джира, джиру, джире ← жира, жиру, жире, Jira (replace «жира», «жиру», «жире», «Jira» only when it is about tasks, not fat; write it in Cyrillic and decline it in Russian: в джире, джиру)
Figma ← фигма, фигме, фигму, фигмы, фигмой
Notion ← ношн, ноушн, ноушен
Confluence ← конфлюенс, конфлюэнс, конфлюенсе, конфлюенса

# Вайб-кодинг
вайб-кодинг* ← вайбкодинг*, вайб кодинг*, вайп кодинг*
чат-бот* ← чатбот*, чат бот*
ИИшн*, ИИшк* ← иишн*, иишк*
ИИшный, ИИшные, ИИшная, ИИшное, ИИшных ← яичный, яичные, яичная, яичное, яичных (only when the text is not about eggs or food)
ИИ-агент* ← и и агент*, ии агент*
Claude ← Клод, Клода, Клоду, Клодом, Клоде
Claude Code ← Клод Код, Клод Кода, Клод Коду, Клод Кодом
Codex ← кодекс, кодекса, кодексом, кодексу, кодексе (only when it is about the OpenAI coding agent, not a legal code)
Cursor ← курсор, курсоре, курсором, курсора (only when it is about the code editor, not the mouse pointer)
GitHub ← гитхаб, гитхабе, гитхабу, гитхаба
пул-реквест* ← пулреквест*, пул реквест*
PR ← пиар (only when it is about code review, not public relations)
задеплоить ← за деплоить
деплой* ← диплой*
закоммитить ← за коммитить
коммит* ← комит*
промпт* ← промт*
LLM ← элэлэм, эл эл эм
API ← апиай, эй пи ай
