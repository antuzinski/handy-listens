# Handy Listens — форк с live captions

Форк Handy для Windows с захватом микрофона и системного звука, настройками Whisper и улучшениями распознавания. Исходники опубликованы в `antuzinski/handy-listens` (main); интеграция релизов Handy и Klava остаётся ручной. Порядок работы описан в `PROJECT_GUIDE.md`, итоговые артефакты сохраняются в `C:\handy-fork`.

## Цели

- Совмещать запись речи с микрофона и звука компьютера для Zoom, видео и других приложений.
- Сохранять улучшения распознавания, словарь и настройки Whisper при интеграции обновлений Handy.
- Делать настройки понятными и визуально согласованными, включая зелёную тему.

## Текущее состояние

- База — Handy v0.9.8 и klava-nevinovata v0.9.8-1 (`.github/upstream-baselines.json`). Порядок обновления, функции форка, которые нельзя потерять, и правила сборки — в `FORK_UPDATING.md`.
- Из Klava перенесены watchdog горячих клавиш, координатор нажатий, атомарные настройки, буфер обмена и автозапуск. Её обработка текста, свой ID с миграцией данных, установщик и updater ещё впереди (`docs/upstream-review-2026-10.md`).
- Словарь `dictionary.txt` (подсказка Whisper, замены для кириллицы, строки для LLM) и промпт `cleanup_prompt.txt` открываются из настроек. LLM-чистка — заготовка до появления API-ключа.
- Captions записывает микрофон и системный звук в одну дорожку; Whisper Turbo — 100 языков; зелёная тема.
- Updater выключен до своего ID и подписи. Рабочая версия пользователя запускается из `src-tauri\target\release`; новые сборки — только в `target\integrate`.
