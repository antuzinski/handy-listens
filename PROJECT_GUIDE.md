## Что сделано

За основу взят Handy с веткой `vscg/Handy` `feat/live-captions`; интегрирован upstream Handy v0.9.7. Captions захватывает микрофон и системный звук в одну дорожку. Добавлены настройки Whisper, пользовательский словарь и обработки распознавания. Исправлены слои выпадающих меню и изумрудный акцент зелёной темы. В каталоге Whisper Turbo проверялся поиск английского языка.

Приложение использует React/TypeScript для интерфейса и Tauri/Rust для аудио и распознавания. Модели загружаются отдельно; пользовательские модели, настройки и история не входят в архив исходников.

## Как запускать и собирать

Сохранённая сборка запускается через `portable\handy.exe`. Рядом нужны DLL и каталог `resources`. Эта сборка сохранена из существующего release-каталога; обновление документации не является новой компиляцией приложения.

Для новой сборки нужны Git, Bun, Rust, Windows C++ Build Tools и зависимости из `BUILD.md`. В исходниках выполните `bun install`, затем `bun run tauri build --no-bundle`. Результат находится в `src-tauri\target\release`. Перед переносом заменяйте комплект целиком, сохраняя пользовательские данные.

## Как обновлять форк

Работайте с `antuzinski/handy-listens`, сохраняя upstream `vscg/Handy` отдельно. Проверка новых выпусков Handy и Klava через GitHub Actions создаёт Issues для ручного разбора. Она не переносит чужие изменения автоматически. После выбора изменений проверьте сборку, распознавание, Captions и настройки, затем публикуйте проверенный коммит.

Автообновление пока выключено. Для его включения нужны собственный ключ подписи, manifest релизов и решение о разделении/миграции пользовательских данных; текущий ID приложения сохранён ради совместимости. Не включайте upstream-обновления вместо канала форка.
